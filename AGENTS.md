## Agent skills

### Issue tracker

Issues live in GitHub Issues. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage labels. See `docs/agents/triage-labels.md`.

### Domain docs

Use the single-context layout. See `docs/agents/domain.md`.

### Releases

A version bump in `Cargo.toml` is a release, and it needs a section in
`CHANGELOG.md` with what's new and fixed, grouped by feature. That section
is the release's notes. See `docs/releasing.md`.
